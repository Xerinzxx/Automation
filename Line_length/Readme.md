# Line Length Counter

This Python script reads a text file and calculates the number of characters in each line (excluding leading/trailing whitespaces), then writes the result to an output file.

## Features

- Counts the number of characters in each line of a text file.
- Outputs results in the format: `Line {n} : {length}`
- Simple and easy to use.

## Requirements

- Python 3.x

## Usage

1. Save your input text in a file named `yourfile.txt` (or any name you prefer).
2. Place the script in the same directory as your input file.
3. Run the script:

```bash
python line_length.py
